# Frontend — Visual Studio Code

1. VS Code → **File ▸ Open Folder** → carpeta `frontend`. Acepta instalar las extensiones recomendadas.
2. Terminal (Ctrl+`): `npm install` y luego `npm run dev` (o Ctrl+Shift+B).
3. Abre http://localhost:5173. Las llamadas `/api` se redirigen al backend en el puerto 8080, que debe estar corriendo.

Comandos: `npm run build` (compila), `npx oxlint` (revisa el código).
